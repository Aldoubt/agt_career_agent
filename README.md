# agt_career_agent

## Personal Career & Academic Agent

`agt_career_agent` is a personal AI-assisted system for managing engineering assets, academic research, resume generation, thesis writing, and interview preparation.

The goal is to transform engineering work into reusable professional assets:

```
Projects
   |
   v
Knowledge Base
   |
   v
AI Career Agent
   |
   +---- Resume
   +---- Thesis
   +---- Figures
   +---- Interview
```

## Main Targets

- Robotics engineering resume
- AI engineering resume
- Graduation thesis support
- Academic figure generation
- Technical interview preparation
- GitHub portfolio management

## Repository Structure

```
knowledge/     Project facts and personal technical assets
resume/       Resume versions
thesis/       Thesis planning and chapters
figures/      Academic figures and diagrams
interview/    Interview preparation
prompts/      AI workflow prompts
scripts/      Automation utilities
```

## Principle

> Store facts first, generate documents second.

The AI assistant must not invent achievements. All generated content should be grounded in the knowledge database.
