# Innovation Points

## 1. GNSS-degraded outdoor localization

Address localization instability in tree-covered outdoor environments by adopting LiDAR-based global localization as the primary absolute positioning source.

## 2. Global localization and continuous tracking fusion

Combine global relocalization for pose initialization/recovery with FAST-LIO2 for high-frequency local state estimation.

## 3. Engineering-oriented autonomous navigation system

Build a complete ROS2 autonomous navigation pipeline integrating perception, localization, planning, control, and tracked robot hardware.
