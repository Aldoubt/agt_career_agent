# 3D LiDAR Autonomous Navigation Project

## Overview

A ROS2 Humble based outdoor mobile robot navigation system designed for GNSS degraded environments.

## System Components

- Hesai MID360 LiDAR
- FAST-LIO2 continuous state estimation
- 3D LiDAR global localization
- Nav2 navigation framework
- Tracked chassis CAN control

## Engineering Challenges

- GNSS degradation under tree coverage
- High vibration chassis platform
- Large-scale point cloud map management
- Reliable navigation recovery

## Engineering Value

Demonstrates complete mobile robot development capability from sensors, localization, navigation to deployment validation.
